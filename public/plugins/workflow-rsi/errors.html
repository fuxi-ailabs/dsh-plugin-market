错误与写操作

常见错误#

情形返回
wrsi-server 没启动或地址错available:false，wrsi-server <url> is not reachable (…)
key_file 不存在或读不了available:false，key file <path> is not readable (ENOENT)
key 错available:false，wrsi-server rejected the key (a restarted server has a new key file)
没配置 wieavailable:false，wie is not configured
所配 wie 版本没有该命令available:false，the configured wie has no "loop list" command
workflow-rsi 返回错误（如会话不存在）available:true, ok:false，error 为服务端原文
/wrsi 子命令或参数写错返回用法说明，不执行

插件不重试，也不在不可用时猜测结果；以上情况会话都正常继续。

写操作的副作用#

命令实际做什么重复执行失败时
admitPOST /api/assets/transition，注册表追加一条准入记录资产已准入时服务端拒绝原样返回服务端错误，注册表不变
publishPOST /api/assets/publish，把资产记录推送到 Workflow owner 的资产仓已推送的提交不会重复产生原样返回错误（未配资产仓时 501）
loop-resumewie loop resume <id> --decision …，闭环账本追加一条恢复记录只对等人或等合入的闭环有效原样返回 wie 的错误输出
plan-decidewie plan decide，工作计划台账追加一条裁决追加新记录，以最后一条为准原样返回 wie 的错误输出

每次写操作只发一次请求或起一次 wie，不自动重试；写入都落在 workflow-rsi 的只追加台账里。

子进程#

wie 用固定的可执行文件与参数数组启动（不经 shell），超时取 timeout_ms，结束即回收。插件不持有其他进程或连接。
