SkillOpt优化你自己的业务 skills

为你已有的业务 skill 自动生成验收、复现问题、提出候选并复测。合格候选可应用到项目，也能回退。

使用场景与适合人群

适合业务 skill 维护者

已有 skill，但没有验收题

“能从我的业务规则直接开始吗？”

选择可导出的文本 skill，提取原文条款，分别生成训练题和独立题，并检查正反样例。可以先开始验证，再检查题目是否覆盖自己的业务。

适合使用 DSH 的业务团队

同一类错误反复出现

“这段执行记录说明 skill 哪里有问题？”

选择当前项目会话或提供业务材料文件。分析会区分 skill、工具、环境和证据不足，只把有出处的问题交给修改者。

适合负责上线的人

修改过了，仍要知道能否应用

“候选是否保住了原来做对的事？”

查看重复评测、逐题回归和文件改动。只有满足资格的候选才可应用到项目；原始资产保留，项目覆盖版本可以回退。

从已有条款到独立复测

参考 MigBot-Lab 与 a2h-opt-loop 的通用主链，运行在本机 DSH，不依赖 Android 或 HarmonyOS。

  • 选择已有 skill → 固定文本快照，读取可选证据。
  • 分析真实条款 → 训练作者和独立作者分别出题 → 校验引用与正反样例。
  • 原生 DSH 重复执行基线 → 修改候选 → 逐题保留无回归的改进，最多三个候选。
  • 最终独立复测 → 查看差异 → 合格后由人应用 → 新会话加载，必要时回退。

提供资产发现、选定轨迹取证、问题归因、自动出题、反思式候选优化、独立语义判据，以及项目版本应用与回退。

手动准备与自动准备

两张本版真实界面展示手动导入套件与自动准备验收题的操作方式。

手动准备：先有套件

手动入口需要自己准备包含训练题和独立题的 suite.json，再导入固定快照。

自动准备：从已有条款出题

选择 skill 后自动提取约束、分别出题并自检，管理页可查看题目和来源，再决定开始优化。

↳ 不要求先手写失败文案或 suite JSON；已有业务记录可作为可选证据。

↳ 运行中的复现、修改和复测自动执行；人负责确认业务标准和最终应用。

↳ 管理页保留 no_change、rejected、inconclusive 等实验结论，可查看逐题结果和候选差异。

安装与第一次验证

下面使用你已有的业务 skill。插件不附带用户的“说人话”资产或原始轨迹。

使用条件
DSH
实际验证为 0.2.1-rc.2；声明兼容 ^0.2.1-rc.2。
本机环境
Node.js 24+；Python 3.11+，可从 PATH 调用或设置 SKILLOPT_PYTHON。本次实测 Windows x64 / Python 3.12.10。
模型凭据
启动 DSH 的进程中需有 DEEPSEEK_API_KEY；默认模型 deepseek-flash。
业务资产
可导出的 UTF-8 文本 bundle，含 SKILL.md。最多100文件、1MB；自动分析另限150000字符。

执行器已内置 DSH 运行依赖；Python仅用标准库。当前仅支持 DeepSeek 官方 API key 路由，业务材料会发送到该模型服务。

适用范围和限制 ＋
自动评测与候选优化

从已有 skill 的条款生成训练题和独立题，重复执行基线，提出候选并逐题检查回归；最终独立复测后展示结论和文件差异。

面向文本类现有 skill

支持现有 skill 的文本/JSON 输出评测，候选最多修改八个已有文件，不执行 scripts。自动生成的合成验收题包含正反样例，可结合业务记录补充用例。

项目版本与调用预算

保留源 skill，合格候选写入项目 .dsh/skillopt，并支持回退。准备最多5次模型请求；优化最多3个候选、100次请求、30分钟活动时间。

常见问题

是否必须提供失败文案和正确答案？＋

不必须。已有 skill 的原文条款可以启动自动出题与评测。业务标准不明确或合成题没有覆盖真实问题时，人补充失败例子和判断有助于改进；插件不会把缺少标准时的模型猜测当成正确答案。最终应用由人触发。

安装后先检查哪里？＋

确认装在当前使用的 profile，重启 DSH。在管理页检查 Python 与模型凭据，或运行 /skillopt doctor。Python不在PATH时设置SKILLOPT_PYTHON。当前不继承任意OAuth或第三方模型provider。

为什么输出 no_change 或候选未通过？＋

no_change 表示没有复现可验证失败，或候选在独立题上没有额外收益；rejected 表示未满足独立通过、稳定增益和无回归；inconclusive 表示运行异常或重复结果波动。可在管理页查看对应的逐题结果；只有 accepted_measured 且运行环境未变的候选可正式应用。

会改全局 skill 或上传业务资产到市场吗？＋

不会覆盖源 skill。项目覆盖版本写到 .dsh/skillopt，实验和轨迹保存在 DSH_HOME/skillopt/workspaces/项目哈希。选中的业务材料会发送给模型服务；原始轨迹和业务 skill 不随插件或市场页面发布。新会话加载新项目版本，旧会话保留原绑定。

提供哪些 skill 优化能力？＋

支持发现现有文本业务 skill、读取选定会话轨迹或业务材料、归因问题、自动生成验收题、优化候选并独立复测。合格候选可应用到当前项目，新会话加载项目版本，需要时可回退。
