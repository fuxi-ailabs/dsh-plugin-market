安装前先确认
使用已有的 DSH 和 Node.js 24+，安装后自动准备并启动本地分析服务。插件源的访问权限沿用现有市场配置。

      
支持平台
Windows x64；DSH 0.2.1-rc.2、Node.js 24+，插件 0.1.0-alpha.4。
自动安装的组件
隔离的 Python、匹配版本的 Core、依赖库和 Viewer。其他系统可使用高级外部服务配置。

      
安装失败可以直接恢复＋
运行缓存损坏会从随包材料重建；安装材料不完整时，在插件详情重新安装此版本。修复保留分析记录，不需要另外配置 Python。
新改动需要刷新快照＋
插件按需生成快照。继续改文件后，发送“刷新当前会话的分析材料”，再查看新增记录。
部分操作可能没有完整记录＋
未导入的会话、缺少成功回执的调用，以及 shell 脚本内部的文件操作，可能留下记录缺口。
查到来源后，仍需验证结果＋
来源和引用能帮你核对过程；代码是否正确、结论是否成立，仍要结合测试和实际结果判断。

完整安装文档 ↗

        
  1. 01
    在 DSH 安装插件
    在「插件」→「发现」添加下方索引，安装 AgentLineage 0.1.0-alpha.4。尚未显示「发现」时，在「实验性插件」旁的「更多」启用「自定义插件市场」。
    插件市场索引
    https://fuxi-ailabs.github.io/dsh-plugin-market/index.json
    完成后应看到AgentLineage 0.1.0-alpha.4 出现在已安装插件中，并开始准备本地分析服务。
    已有旧版本时，先卸载再安装新版，分析记录和会话绑定会保留。安装同时提供 Windows x64 运行环境；若 DSH 提示需要重启，按提示完成重启。
  2. 02
    确认已经就绪
    打开已安装的 AgentLineage 详情，等待“AgentLineage 已就绪”。也可发送下面的提问检查能力。
    发送给 DSH
    请调用 lineage_status，确认 Core 能力包含 dsh-native-v4。不要显示任何 token。
    完成后应看到页面显示“AgentLineage 已就绪”；lineage_status 的 runtime.state 为 ready，能力包含 dsh-native-v4。
    若出现校验失败、目录占用或超时，页面会显示具体原因和重试操作。无需打开终端安装 Core。
  3. 03
    运行发布说明例子
    复制下面的提问，让 DSH 创建发布说明并修改两次，再查询改动来源。
    发送给 DSH
    请用 DSH 的 write 工具创建 release-note.md，内容为“# 搜索功能发布说明\n功能：新增搜索\n状态：草稿”；再用 edit 分两次修改：先把“新增搜索”改为“支持标题和标签搜索”，再把“草稿”改为“待评审”。不要使用 shell 写文件。完成后刷新当前会话的 Lineage 快照，查询这个文件的三次写入，给出来源会话、调用、成功回执和原文引用。
    完成后应看到release-note.md 有三次确认写入；最后一次将“草稿”改为“待评审”，并有对应的调用和回执引用。
  4. 04
    打开视图查看记录
    让 DSH 打开当前快照的 Viewer，选中文件并展开 diff。后续又改了文件时，刷新快照再查询。
    发送给 DSH
    打开当前分析快照的 Viewer。
    完成后应看到选中 release-note.md 后，能查看三次写入及对应的 diff。
    从插件详情点击“打开溯源视图”，或使用 lineage_open 返回的同源地址；复用 DSH 登录，无需读取或粘贴 Core 凭据。
