DSH PLUGIN · v1.0.0

Skill 评测

从 Skill 列表开始，构建评测题集、检查覆盖率与基线，运行 Eval / Trigger，并汇总 Gate 和 HTML 报告。

DSH
0.2.1-rc.2
Node.js
>=24
Bundle
@fuxi-ailabs/dsh-eval-bundle

功能

  • Skill 工作台：浏览 System、Global、工作区和手动路径中的 Skill。
  • 题集构建：初始化、追加题目、生成配置，并查看 evals.json 预览。
  • 质量与基线：检查覆盖率、静态审阅题集并冻结基线。
  • 执行验证：支持 Skill A/B Eval、Trigger 测试和真实任务 Run。
  • 判决与报告：执行 Gate 并生成可浏览的静态 HTML 报告。
  • 环境检查：在插件配置页检查 SIFT、Provider Auth 和评测服务。

安装

npm 包@fuxi-ailabs/dsh-eval-bundle
查看 npm 页面 ↗

1. 准备运行环境

  • DSH 0.2.1-rc.2 或同一兼容范围。
  • Node.js 24 或更高版本。
  • sift 命令已安装并在 PATH 中。
  • 生成题目、执行评测或 AI 语义评审时，准备可用的 Provider 凭据。

2. 从市场安装

在 DSH 的插件市场中添加索引，找到 Skill Eval · Skill 评测 并安装。

https://fuxi-ailabs.github.io/dsh-plugin-market/index.json

也可以直接安装当前版本：

dsh plugin --profile <profile> add @fuxi-ailabs/dsh-eval-bundle@1.0.0

安装后重启 DSH。

环境检查

在「插件」→ Skill Eval 的配置页检查运行依赖。检查只读取环境，不修改插件配置。

检查项说明
SIFT必需。检查 sift 是否可执行，并提供缺失时的安装指引。
Provider Auth可选。生成题目、调用模型和 AI 语义评审需要可用凭据。
Eval Suite Service检查 Host 是否已挂载 evalSuite 服务。

使用

  1. 打开左侧「Skill评测」。
  2. 选择已有 Skill，或通过「添加路径」加入 Skill 目录。
  3. 在右侧从「题集构建」开始，逐步完成题集、基线、执行和报告。
  4. 也可以使用「试跑」快速验证 Skill，或在命令行执行完整的 /eval-suite 工作流。

评测流程

阶段能力
1. 题集构建初始化 evals.json、追加题目、生成配置并预览题目。
2. 质量与基线检查覆盖率、静态审阅题集，并冻结后续比较使用的基线。
3. 执行验证执行 Skill A/B Eval、Trigger 测试或真实任务 Run。
4. 判决与报告运行 Gate，查看通过情况并生成 HTML 报告。

常用命令

/eval-suite init <skill-path>
/eval-suite coverage <skill-path>
/eval-suite inspect <evals-path>
/eval-suite eval <skill-path> --evals <evals-path>
/eval-suite trigger <skill-path> --evals <evals-path>
/eval-suite run <skill-path> --task "<task>"
/eval-suite gate <benchmark-path>
/eval-suite report <workspace>

Agent 声明可使用 --kind agent 进行绝对质量评测。

使用条件与限制

  • 实际试题生成、模型调用和执行验证会消耗时间与模型额度。
  • 评测质量取决于 Skill 声明、题集覆盖、任务输入和执行环境。
  • inspect 只静态审阅 evals.json，不会产生通过或失败判决。
  • Gate 与报告需要已有执行产物；不要用未完成的运行结果判断 Skill 质量。
