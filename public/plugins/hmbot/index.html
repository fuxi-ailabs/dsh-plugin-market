安装并开始迁移

使用条件
DSH
已通过 0.2.1-rc.2 与 0.2.2-rc.1 原生接入检查；桌面需配置可用模型。
工具链
devecocli、HarmonyOS SDK 与 HDC。桌面版 DSH 自带运行时；命令行版 0.2.2 需要 Node.js 24.9+。设备组件随包提供，投屏无需额外 Java。
服务与设备
可用的模型和鸿蒙知识服务；显式选择模拟器或真机，不自动接管其它任务设备。

安装包不包含 SDK、设备镜像、模型凭据或知识库正文。

适用范围和限制 ＋
流程保持 0.1.5

核心 command、角色、共同原则与迁移技能保持源文件一致，宿主映射独立维护。

设备范围

设备接口要求 API 12+ 与 UiTest 扩展；已验证 macOS arm64 + API 24 / UiTest 6.0.2.3 模拟器，同一设备同时由一个窗口连接。

结果有边界

Succeeded 表示相应操作或子任务有成功回执，不等于整个应用已覆盖全部功能。

    安装 Bundle 从 npm 安装 @fuxi-ailabs/hmbot；桌面用户在插件管理器填写完整包名和版本，本地验证也可添加预构建包的绝对路径。 终端

常见问题

必须启动浏览器或本地看板吗？＋

不需要。工作台通过 DSH 原生侧栏与宿主连接加载。

和 DSH 默认 workflow 会竞争吗？＋

HMBot 使用独立工具名，在 HMBot 会话内限定调度入口；普通 DSH 会话仍保留原有工具。

如何减少迁移中的权限审批？＋

对于可信工程，在 DSH 会话输入框旁选择「完全访问 / Full access」。新启动的子任务继承权限；默认工作区模式仍可读取源码和 SDK、修改工作区代码。

安装包是否包含 SDK、截图和演示视频？＋

不包含。包内提供插件、技能、使用说明与设备侧预编译组件；SDK 和 CLI 复用本机安装，演示截图由本市场页面托管。
