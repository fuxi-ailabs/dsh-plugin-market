记忆工具

插件为 Agent 注册三个工具，每个工具返回一段文本。记忆服务不可用时返回「记忆暂不可用」，见错误码。

工具作用提供条件
memory_search按报错或关键词检索记忆，最多返回 5 条，每条带出处和命中理由总是提供
memory_read按记录编号读取全文总是提供
memory_note记下这次学到的东西，从下一个会话起可见插件配置 notes 不为 false

memory_search#

参数类型必填说明
querystring是错误文本、工具名或问题描述，最多 2000 字符
limitinteger否1～5，默认 5

插件会自动附上本会话最近一次失败的工具名和错误信息。返回示例：

text
1. [lr_01a163fbe95e791e8c5c45763b9e6937] Link zlib with -lz
   source: 本机自动确认 · zlib-port · 2026-10-22 · 记录时会话结局：未知
   matched: error_signature sha256:d3edaf502f6fc7121… (0.30), code_symbol deflate (0.20), lexical deflate,ld,symbol,undefi… (0.15), same_project zlib-port (0.10), environment os=darwin (0.05), recency 0d (0.05), tool_name bash (0.05), trust local_auto (0.03), evidence sources=1,used_success=0 (0.01)
   ld: undefined symbol deflate

matched 列出全部排序信号和各自的贡献值。

没有命中时返回 no matching memory。本会话写的笔记不会出现在结果中。

memory_read#

参数类型必填说明
refstring是记录编号，例如 lr_…、rr_…

返回记录全文：

text
[lr_01a163fbe95e791e8c5c45763b9e6937] Link zlib with -lz
source: 本机自动确认 · zlib-port · 2026-10-22 · 记录时会话结局：未知

Link zlib with -lz（lr_01a163fbe95e791e8c5c45763b9e6937）
出处：本机自动确认 · zlib-port · 2026-10-22 · 记录时会话结局：未知
类型：bugfix · 范围：project
现象（What）：ld: undefined symbol deflate
原因（Why）：zlib was not on the link line
位置（Where）：Makefile LDLIBS
做法（Learned）：add -lz after the object files

记录附了修法时，末尾还有一行「修法（Fix，命令）」或附带的补丁、文件内容；团队核验记录另有一行「核验」。

每个会话累计读取的字数有上限，默认 20000 字符。

memory_note#

参数类型必填说明
titlestring是简短、便于检索的标题，最多 160 字符
typeenum是decision、bugfix、pattern、config、discovery、learning、pitfall
scopeenum是project（只用于本项目）或 global
contentobject是what、why、where、learned 四项都必填
topic_keystring否两级主题，例如 build/zlib-link。同一主题再次记录时更新原笔记
fixobject否验证过的修改，三选一：{kind:'command', command}、{kind:'diff', diff}、{kind:'config', path, content}
evidence_refsstring[]否支撑这条笔记的记录编号
relates_toobject[]否{record_ref, relation}，指出已有记录错误或过时

返回示例：

text
saved lr_01a163fbe95e791e8c5c45763b9e6937 revision 1 under build/zlib-link; no similar memories found

有相似记录时，返回中会列出它们。附了 fix 的笔记可以被团队记忆回放验证，见团队记忆。
