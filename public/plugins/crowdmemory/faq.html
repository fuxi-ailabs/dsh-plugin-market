常见问题

记忆服务没有启动会怎样？#

会话照常进行。插件不推送，记忆工具返回「记忆暂不可用」。记忆服务启动后，新会话自动恢复。

安装需要联网吗？#

npm install 需要从 npm 下载包。之后的 crowdmemory-runtime install 不联网，包内已包含所有组件。

写下的笔记什么时候能用？#

从下一个会话开始。同一个会话写的笔记不会推送给自己。

会上传我的代码吗？#

本机记忆不上传。记录写入前会去掉密钥、令牌和家目录路径。详见隐私与安全。

支持 DSH 以外的 Agent 吗？#

记忆服务的接入协议 memory-agent-ingress/v1 与宿主无关。0.1.0 只提供 DSH 插件。

记录会被清理吗？#

记忆库不会自动清理。会话状态保留 30 天。

怎么反馈问题？#

发邮件到 cacheline999@gmail.com，请附上 crowdmemory-runtime status --json 的输出、插件与 DSH 的版本，以及出错的会话日志。
