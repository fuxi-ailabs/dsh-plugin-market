记忆服务命令上限与超时隐私与安全

记忆服务命令

crowdmemory-runtime 命令由 npm 包 @fuxi-ailabs/crowdmemory-runtime 安装。所有命令都接受 --prefix <目录>（默认 ~/.crowdmemory）。

命令#

命令说明
install安装、升级或回滚
start前台运行记忆服务。已经在运行时拒绝启动第二个
status [--json]查询运行状态：会话数、模板、最近错误
version [--json]包版本、组件版本和当前安装的版本
prune [--keep N] [--dry-run]删除旧版本，默认保留当前和上一个
uninstall [--keep-state]卸载。加 --keep-state 保留记忆库和配置

退出码：0 成功；1 记忆服务没有运行或没有安装；2 用法或环境错误，例如找不到合适的 Python、包校验失败。

install 选项#

选项说明
--prefix <目录>安装目录，默认 ~/.crowdmemory，也可以用 CROWDMEMORY_RUNTIME_PREFIX
--python <路径>用于建虚拟环境的 Python。默认沿用上次的，没有时在 PATH 中查找
--service none|launchd|systemd生成用户服务文件，默认 none。只生成不加载，加载命令会打印出来
--profile session-default|workflow-default首次安装时的默认模板
--socket <路径>首次安装时的套接字路径。macOS 上不能超过 103 字节
--json输出 JSON

目录#

路径内容
<prefix>/releases/<id>/每个版本一个目录，含独立的虚拟环境
<prefix>/current指向当前版本
<prefix>/host-config.json记忆服务配置。首次安装时生成，之后不会被覆盖
<prefix>/state/记忆库、令牌、endpoint.json。升级时保留
<prefix>/service/生成的服务文件

升级与回滚#

bash
npm install -g @fuxi-ailabs/crowdmemory-runtime@<版本>
crowdmemory-runtime install

current 原子切换到新版本，state/ 和 host-config.json 保留。正在运行的记忆服务要重启后才使用新版本。回滚用同样的两步，装回旧版本。

卸载#

bash
crowdmemory-runtime uninstall
npm uninstall -g @fuxi-ailabs/crowdmemory-runtime

加载过服务文件时，先停止服务：macOS 执行 launchctl bootout gui/$(id -u)/com.crowdmemory.runtime，Linux 执行 systemctl --user stop crowdmemory-runtime.service。
