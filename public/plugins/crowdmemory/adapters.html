Fuxi通用DSH组件市场 /Crowd Memory v0.1.1

接入你的 Agent framework

Adapter 把宿主的事件和调用转换为 CrowdMemory 接入协议，并把查询结果送回 Agent。更换 framework 时，替换对应 adapter；任务阶段和失败判定继续由自己的工作流提供。

在独立目录试用 OpenClaude 插件

npm 发布完成前，从已合入的源码构建并解包使用，无需全局安装插件。先按配置文档启动 Runtime，再将下方端点路径和项目名替换为自己的值。

git clone https://gitcode.com/third-party-library-for-harmony/CrowdMemory.git
cd CrowdMemory/distributions/memory-adapter-openclaude
npm install --ignore-scripts --package-lock=false
npm run build
npm pack
mkdir -p plugin
tar -xzf fuxi-ailabs-crowdmemory-openclaude-plugin-0.1.1.tgz -C plugin
CROWDMEMORY_ENDPOINT_FILE="/absolute/path/to/runtime/state/endpoint.json" \
CROWDMEMORY_PROJECT="my-repository" \
CLAUDE_CODE_DISABLE_AUTO_MEMORY=1 \
openclaude --plugin-dir "$PWD/plugin/package"

会话初始化应显示 MCP 服务 plugin:crowdmemory:memory 已连接，Agent 可调用三个记忆工具。让会话 A 写入 memory_note 并结束，再在会话 B 用 memory_search、memory_read 核对来源。不加 --bare，该选项会跳过插件。持久安装方式和环境变量见OpenClaude 插件指南。

代码放在哪里

  • CrowdMemory 仓库维护各 framework adapter；DSH 与 OpenClaude 共用适配器核心，包括 Runtime 客户端、错误签名、脱敏、推送包装、记忆工具与协议快照。
  • 使用方保留自己的任务、阶段、失败事实和门禁。MigBot-Air 是使用方，通用插件不依赖其代码或迁移流程。
  • Runtime 管理记忆存储、召回、来源与信任。Adapter 不替使用方判断任务成功。

源码与开发指南

公共核心是仓库内的唯一源码，由同步脚本拷入各 adapter 再独立构建；不作为额外运行时依赖发布。新增 adapter 只实现宿主事件到规范事件的转换。

  • Framework adapter 开发指南：协议、事件映射、职责与验收要求。
  • 适配器公共核心：在该目录用 npm run update 下发公共改动并测试；用 npm run adopt -- <adapter> 收回副本修改。脚本不提交、不发布。

已合入：#8 OpenClaude 插件、#10 公共核心。源码合入与 npm 发布是两个状态。
