Fuxi通用DSH组件市场 /Crowd Memory v0.1.1

接入你的 Agent framework

Adapter 把宿主的事件和调用转换为 CrowdMemory 接入协议，并把查询结果送回 Agent。更换 framework 时，替换对应 adapter；任务阶段和失败判定继续由自己的工作流提供。

支持状态

宿主状态接入范围
DSH已发布 0.1.1会话与 workflow 事件、工具结果、推送、记忆工具。安装与验证
OpenClaude源码开发预览派子代理前召回、结束前提醒、结束时采集笔记，另提供 JSON bridge。尚未发布 Python 包或完成设备验收。

OpenClaude 预览使用独立 Python 环境与同用户 Runtime，不依赖 DSH；不能直接套用 DSH 的 npm 安装命令。目标 OpenClaude 版本的 hook 合同需验证，Claude Code 兼容性尚未验收。

代码放在哪里

  • CrowdMemory 仓库维护通用 framework adapter、Client 协议映射、开发指南与合同测试。
  • 使用方保留自己的任务、阶段、失败事实和调用时机；已有 hooks 的框架通过 JSON bridge 接入，避免重复修改输入。
  • Runtime 管理记忆存储、召回、来源与信任。Adapter 不替使用方判断任务成功。

源码与开发指南

开发预览的指南和独立安装步骤见下方源码链接。当前没有可安装的 OpenClaude npm 插件，也不应尝试安装尚未发布的 Python 包名。

  • CrowdMemory adapter 分支与开发指南：docs/crowdmemory/adapters.md、distributions/memory-adapter-openclaude/README.md。
  • MigBot-Air 工作流接入预览：docs/crowdmemory-integration.md；显式开启，保留原工作流门禁与原始笔记留档。

实现评审：CrowdMemory #8 · MigBot-Air #429。合并和发布前，OpenClaude 相关接入均为源码预览。

当前验证范围是合同测试、真实 Unix socket 上的笔记写入与跨会话读取、工作流 JSON 往返及异常降级。完整模型任务与生产设备验收需单独记录。
