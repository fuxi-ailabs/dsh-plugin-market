工作流记忆

工作流记忆按 DSH workflow 的运行和阶段组织记忆。一次 workflow 运行算一个任务，阶段开始时推送这个阶段以前积累的记录。

启用#

安装记忆服务时选择 workflow-default 模板：

bash
crowdmemory-runtime install --profile workflow-default

或者在 DSH 启动前设置：

bash
export CROWDMEMORY_PROFILE=workflow-default

行为#

事件处理
workflow 开始、结束记为一个任务的开始和结束
阶段开始按阶段检索，推送放进该阶段每个子 Agent 的第一步
子 Agent 开始、结束记入所属阶段
目标变更（goal/changed）记入任务

插件配置 workflow: false 时不处理以上事件。模板不按 workflow 组织记忆时，记忆服务忽略这些事件。
