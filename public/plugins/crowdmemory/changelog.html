0.1.1（2026-11-02）#

  • Runtime 和适配器发布到 @fuxi-ailabs scope，安装命令固定 0.1.1，DSH bundle 注册名与 npm 包名一致。
  • 公开开发评测数据、真实运行观测和离线复算入口，包括开关记忆与固定 Episode 提炼对照，见 评测与适用范围。
  • Runtime Python 组件为 0.1.1，接入协议为 memory-agent-ingress/v1，两个默认模板为 0.3.0（r3）。
  • 安装说明使用项目本地 npm 依赖与独立 Runtime prefix；跨机器开发协作仍为内部预览。
  • DSH 插件 @fuxi-ailabs/crowdmemory-dsh-adapter：会话开始、工具失败后、workflow 阶段开始时推送；memory_search、memory_read、memory_note 三个工具。
  • 本机记忆服务 @fuxi-ailabs/crowdmemory-runtime：离线安装，支持升级、回滚和用户服务。
  • 两个模板：session-default、workflow-default。
  • 支持 DSH 0.1.6-alpha.2 || ^0.2.0-rc.2。
  • 插件默认读取 ~/.crowdmemory/state/endpoint.json，桌面版不需要额外配置。
  • 按任务统计是否用了记忆及成功率。
  • 团队记忆与自动核验（内部预览）。
  • Apache-2.0。
