DSH PLUGIN · v1.0.0

Skill 静态检查

在一个工作台中检查 Skill 和 Agent 声明：运行 11 项规范检查与安全扫描，并按需启用 AI 内容评审。

DSH
0.2.1-rc.2
Node.js
>=24
Bundle
@fuxi-ailabs/dsh-static-check-bundle

功能

  • 统一工作台：按 System、Global、工作区和手动路径浏览检查对象。
  • 规范检查：执行 SIFT 的 11 项确定性 Skill 声明检查。
  • 安全扫描：汇总内置扫描与可选的 aguara、skill-scanner 结果。
  • AI 内容评审：按需调用模型评审声明内容，不会默认开启。
  • 环境检查：在插件配置页检查 SIFT、扫描器、Provider Auth 和静态检查服务。

安装

npm 包@fuxi-ailabs/dsh-static-check-bundle
查看 npm 页面 ↗

1. 准备运行环境

  • DSH 0.2.1-rc.2 或同一兼容范围。
  • Node.js 24 或更高版本。
  • sift 命令已安装并在 PATH 中。
  • aguara、skill-scanner 为可选外部扫描器。
  • AI 内容评审需要可用的 Provider 凭据。

2. 从市场安装

在 DSH 的插件市场中添加索引，找到 Static Check · Skill 静态检查 并安装。

https://fuxi-ailabs.github.io/dsh-plugin-market/index.json

也可以直接安装当前版本：

dsh plugin --profile <profile> add @fuxi-ailabs/dsh-static-check-bundle@1.0.0

安装后重启 DSH。

环境检查

在「插件」→ Static Check 的配置页检查运行依赖。检查只读取环境，不修改插件配置。

检查项说明
SIFT必需。检查 sift 是否可执行，并提供缺失时的安装指引。
aguara / skill-scanner可选。外部安全扫描器缺失时显示警告，不阻止规范检查。
Provider Auth可选。仅 AI 内容评审需要可用的模型凭据。
Static Check Service检查 Host 是否已挂载 staticCheck 服务。

使用

  1. 打开左侧「静态检查」。
  2. 选择已有 Skill，或通过「添加路径」加入本地 SKILL.md、Skill 目录或 Agent 声明。
  3. 选择「规范检查」「安全扫描」或「内容评审」。
  4. 运行当前检查，并在右侧查看评分、问题、扫描器和内容对照。

三类检查

检查行为
analyze执行 11 项确定性规范检查，不调用 LLM。
vet执行安全扫描；可勾选「跳过外部扫描器」，只运行内置 secrets-scan 与 structure-check。
critique调用模型进行内容评审，会产生模型调用、耗时和费用。

命令行

/skill-check <path> --checks analyze,vet
/skill-check <path> --checks analyze,vet,critique
/skill-check <agent.md> --kind agent

Agent 声明目前只支持 critique 内容评审。

使用条件与限制

  • 静态表示目标 Skill 不会被执行，但 AI 内容评审仍会调用模型。
  • 安全扫描的完整程度取决于外部扫描器是否安装及本机环境。
  • 大型目录建议勾选「跳过外部扫描器」，避免外部扫描器超时。
  • 手动路径保存在 DSH Home 下的 dsh-static-check 目录。
